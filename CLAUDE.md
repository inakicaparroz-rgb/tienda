# Flujo de creación de prompts

Esta sesión se usa para crear prompts que luego se envían a otras sesiones (campañas de Meta Ads, edición de imágenes, copywriting, etc.).

Antes de entregar un prompt final al usuario, pasarlo por el skill `grill-me` (entrevista para afilar el plan/diseño) para cuestionarlo y mejorarlo, y recién después mostrar la versión definitiva.
